Pobrane dane: 

SRA.sh   --> najpierw znalazłam na stronie NCBI próbę virusa z zadania (https://www.ncbi.nlm.nih.gov/biosample/SAMN33344176/), następnie wybrałam numer SRR (https://www.ncbi.nlm.nih.gov/sra/SRX19493981[accn]) zdecydowałam się na zmodyfikowaną wersje. Dane, które wykorzystałam w projekcje to: SRR23609077. Kod tworzy najpierw folder o nazwie SRR23609077 w którym umieszcza pobrane dane sekwencji a następnie tworzy folder input, w którym umieszcza rozpakowane pliki 1 i 2 fastq. 

adapter.sh --> tworzy folder o nazwie adapters. Ściąga adapter potrzebny do trimmingu.

genomreferencyjny.sh --> tworzy folder o nazwie genom i pobiera genom referencyjny. 


Pliki: 

config.yaml --> plik konfiguracyjny 

Snakefile 

main.nf --> Nextflow 


Struktura katalogu głównego: 

-pliki: SRA.sh, adapter.sh, genomreferencyjny.sh, graf.png, Snakefile, main.nf
-foldery: SRR23609077, adapters, genom, input, output 

Folder SRR23609077 zawiera plik SRR23609077.sra
Folder adapters zawiera plik TruSeq3-PE.fa
Folder genom zawiera pliki NC_045512.2.fasta, NC_045512.2.amb, NC_045512.2.ann, NC_045512.2.bwt, NC_045512.2.fai, NC_045512.2.pac, NC_045512.2.sa
Folder input zawiera pliki SRR23609077_1.fastq.gz i SRR23609077_2.fastq.gz


Opis uruchomienia: 

W terminalu należy uruchomić trzy pliki pobierające dane: SRA.sh, adapter.sh, genomreferencyjny.sh. 
Należy osobno utworzyć katalog output. 
Poleceniem: conda activate snakemake -  aktywuje środowisko snakemake. 
Poleceniem: snakemake --cores 4   - aktywuje Snakefile 
Polecenie: nextflow run main.nf -with-docker  - aktywuje Nextflow
Poleceniem: snakemake --dag | dot -Tpng > graf.png    - tworzę graf DAG 

Plik Snakefile tworzy foldery w output z określonymi plikami: fastqc_raw, trimmed, fastqc_trimmed, bam, coverage, variants, multiqc

System działania Snakefile: 
FastQC przed trimmingiem -> Trimmomatic -> FastQC po trimmingu -> indeksowanie genomu -> sortowanie BAM -> indeksowanie BAM -> ocena pokrycia -> detekcja wariantów -> MultiQC.


System działania Nextflow: 
FastQC przed trimmingiem -> Trimmomatic -> FastQC po trimmingu
